# Support

## Getting Help

- Use GitHub issues for reproducible bugs, documentation problems, and feature requests.
- Use [SECURITY.md](SECURITY.md) for vulnerability reporting.

## What To Include

Please include:

- the command, route, or UI flow you used
- the expected behavior and actual behavior
- relevant logs or screenshots with secrets redacted
- your Python version and how you ran the app (`uv run`, Docker, or RHEL deployment)

## Support Boundaries

This project is maintained on a best-effort basis. There is no formal SLA or
commercial support offering.
