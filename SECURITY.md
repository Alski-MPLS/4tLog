# Security Policy

## Reporting a Vulnerability

Please do not open public issues for suspected vulnerabilities.

Use GitHub's private vulnerability reporting for this repository if it is enabled.
If private reporting is unavailable, contact the maintainer privately through the
repository owner's GitHub profile before disclosing details publicly.

Include:

- affected version or commit
- impact summary
- reproduction steps or proof of concept
- any suggested remediation

## Scope

This project handles local authentication, session management, CSRF protection,
and connectivity to FortiAnalyzer appliances. Reports involving secrets handling,
authentication, authorization, session integrity, and unsafe defaults are in scope.

## Disclosure Expectations

Please allow time to investigate and remediate before public disclosure. After a fix
is available, coordinated disclosure is welcome.
